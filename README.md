# 輕度認知障礙檢測遊戲 點心茶樓
一、 遊戲開始前的基本設定
在正式開始前，請先在首頁畫面上設定好以下資料：
 * 挑戰份量：請確認選擇「研究一席・251 次（含記憶暖身）」（大約需要 12–16 分鐘，不含說明與休息時間）。
 * 作答節奏：保持預設的「從容・預設」即可（研究版會自動採固定節奏）。
 * 玩家／受試者編號：請輸入我們分配給您的專屬編號（例如：S001）。
 * 年齡與性別：請填寫您的實際年齡，並在下拉選單選擇您的性別（只作人口學分組研究之用）。
 * 使用設備：確認已選好您目前使用的裝置（如「電話」或「平板」），開啟觸控模式後直接用手指點擊螢幕按鍵即可。
(填妥後，點擊*「開始四關挑戰」*即可順序遊玩第 1 關至第 4 關！)
二、 遊戲玩法講解（4 個茶樓關卡）
請放輕鬆、照著直覺點擊螢幕按鍵即可：
 * 第 1 關：蒸籠出爐（運動基線 SRT）
   * 怎麼玩：螢幕一出現白色的蒸籠，請立刻按一下單一按鍵。
 * 第 2 關：奉茶與蝦餃（選擇反應 CRT）
   * 怎麼玩：看到藍色圓形茗茶請按左邊，看到橙色方形蝦餃請按右邊。
 * 第 3 關：揀選靚點心（衝動抑制 Go/No-Go）
   * 怎麼玩：看到綠色點心請立刻按下去；看到紅色警告請忍住不要按。
 * 第 4 關：點心連連看（記憶 1-Back）
   * 怎麼玩：記住上一籠點心，比對現在這籠和上一籠是不是一樣。不同請按左邊，相同請按右邊。
三、 遊戲完成後：如何匯出並傳送資料給我們
由於完成成績只儲存在您目前使用的手機／平板瀏覽器中（清除瀏覽資料可能會令紀錄消失），請務必依照以下步驟匯出檔案並發送給研究團隊：
 * 在成績結算頁直接匯出：
   * 全部 4 關完成後，畫面會進入「反應與準確度」成績頁。
   * 請直接點擊畫面上的綠色按鈕 「匯出特徵 CSV」，將數據檔案下載並儲存到手機或平板中。
 * 如果已經返回首頁（補匯出方法）：
   * 滑動到首頁最下方的 「最近的挑戰」 區塊。
   * 核對清單上顯示的玩家編號（如 S001）、日期時間及挑戰份量（請確認為「研究一席」而非「32次短版」）。
   * 點擊該筆紀錄右側的 「查看」 按鈕，即可重新進入成績頁，再點擊 「匯出特徵 CSV」 下載檔案。
 * 發送檔案給研究團隊：
   * 請將下載好的 .csv 檔案透過 WhatsApp 或 電郵 直接傳送給我們，即完成本次資料收集！
